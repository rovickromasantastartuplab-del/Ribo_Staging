# Few-Shot Examples

## Example 1: Repeated Objections
- Triage history shows recent `objection`, `objection`, and `misaligned` states with strained tone.
- Output should preserve repeated friction as durable memory instead of treating the relationship as freshly neutral.
- Relationship strength should stay `weak` or `moderate`, never `strong`.

## Example 2: Closed Lost Then Reopened
- History shows a prior `closed_lost` thread followed by a latest inbound `reopened` state.
- Output should preserve the revival event explicitly and keep the relationship cautious.
- Relationship strength should cap at `moderate` until later business motion proves `active`.

## Example 3: Steady Healthy Engagement
- Multiple recent threads show `active` state, positive health, and heating/stable momentum.
- Output should preserve repeated healthy engagement as durable trust and commercial momentum.
- Relationship strength may be `strong` when the pattern is sustained.

## Example 4: Stalled Relationship
- Latest triage state is `stalled` after earlier decent engagement.
- Output should preserve the slowdown and recommend caution in memory points.
- Relationship strength should not overstate momentum; `moderate` or `weak` is appropriate.
