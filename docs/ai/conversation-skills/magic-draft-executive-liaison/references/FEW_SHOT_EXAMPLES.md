# Few-Shot Examples

## Example 1: Demo Follow-Up
Input intent: sales with active interest.
Good output style:
- Subject is clear and specific.
- Body confirms context and offers two scheduling windows.
- Ends with one direct question.

## Example 2: Pricing Clarification
Input intent: pricing request.
Good output style:
- Body answers pricing ask directly.
- Clarifies assumptions briefly.
- Asks for one confirmation to proceed.

## Example 3: Re-Engagement
Input intent: cold lead returned.
Good output style:
- Acknowledges renewed interest.
- Suggests a low-friction next step.
- Uses neutral, non-pushy language.

## Example 4: Billing-Sensitive Thread
Input intent: billing concern with relationship risk.
Good output style:
- Empathetic opening.
- Clear ownership and action taken.
- Concrete timeline and single confirmation request.
